```markdown
# Список желаний

Небольшое приложение для создания списка вещей, которые пользователь хочет купить.

## Возможности

- Добавление вещей с названием и ценой
- Проверка правильности введённых данных
- Отметка вещи как купленной
- Удаление вещей
- Счётчик всех записей
- Сохранение списка в localStorage
- Восстановление списка после перезагрузки страницы
- Сообщение при пустом списке

## Технологии

- HTML
- CSS
- JavaScript
- localStorage
```
